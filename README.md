# أجندة الخبير القضائي — LexEnginuity Edition ⚖️📱

تطبيق ويب تقدمي (PWA) وتطبيق هاتف متكامل مخصص لخبراء وزارة العدل المصرية لتنظيم المأموريات، الجلسات، المعاينات الميدانية، والمواعيد القضائية بدقة متناهية مع العمل الكامل بدون إنترنت (100% Offline).

---

## 🌟 أبرز مميزات التحديث الجديد (v2.3)

1. **دعم المظهرين (الداكن والنهاري - Dark & Light Themes):**
   - زر تبديل تفاعلي وسلس من شاشة الإعدادات للتحويل بين المظهر الليلي الفاخر والمظهر النهاري النقي.
   - تكييف كامل لجميع الشاشات ونوافذ البحث والتقارير في كلا المظهرين.

2. **العمل دون اتصال بالإنترنت (100% Offline):**
   - تخزين محلي كامل عبر Service Worker وقاعدة بيانات IndexedDB سريعة.
   - تضمين كافة الخطوط (Cairo و Outfit) ومكتبة FontAwesome محلياً دون الحاجة لأي اتصال بالإنترنت.

3. **التقويم القضائي المصري الذكي:**
   - تمييز الإجازات الرسمية للدولة، وتطبيق قرار رئيس مجلس الوزراء رقم 1249 لسنة 2020 لترحيل الإجازات ليوم الخميس مع إمكانية تفعيل أو إلغاء الترحيل بضغطة زر.
   - تمييز المناسبات الدينية والاجتماعية (بداية رمضان، ليلة القدر، عيد الأم) باللون الأزرق المميز مع بقائها كيوم عمل في المحاكم.

4. **نافذة البحث الشامل الذكي:**
   - بحث فوري بالأرقام، أسماء الخصوم، المحاكم، والإجراءات مع تصفيات سريعة (القادمة، المأموريات، المواعيد).
   - تمييز الكلمات المطابقة مع الانتقال المباشر للملف في الأجندة.

5. **منظومة التنبيهات المزدوجة:**
   - تنبيه مسبق قبل الموعد بـ 24 ساعة للتحضير.
   - تنبيه عاجل قبل الموعد بساعتين.

6. **تصدير واستيراد البيانات:**
   - مشاركة وحفظ النسخ الاحتياطية عبر WhatsApp، البريد، أو الذاكرة المحلية لضمان عدم فقدان أي بيانات.

## 📲 طريقة تشغيل التطبيق وتثبيته على الآيفون (iPhone / iPad)

التطبيق مصمم كـ **Progressive Web App (PWA)** بمواصفات Apple الرسمية:

1. افتح متصفح **Safari** على جهاز الآيفون.
2. ادخل على رابط المشروع المباشر:  
   👉 **`https://engamrhamed.github.io/legal-agenda/`**
3. اضغط على أيقونة **المشاركة (Share)** أسفل الشاشة ⎋.
4. مرر لأسفل واختر **«إضافة إلى الشاشة الرئيسية» (Add to Home Screen)**.
5. اضغط على **«إضافة» (Add)** بالأعلى.

> 🎉 **مبروك!** سيظهر التطبيق فوراً على شاشة جهازك بأيقونته الرسمية، وبمجرد لمسه يفتح كشاشة كاملة وتطبيق آيفون مستقل تماماً ويعمل في أي وقت بدون إنترنت.
